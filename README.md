# QuizPlatform

QuizPlatform — учебное веб-приложение для создания и проведения интерактивных квизов.

Проект разрабатывается для практического освоения ASP.NET Core MVC, Entity Framework Core и PostgreSQL.

## Технологии

- C#
    
- ASP.NET Core MVC
    
- Entity Framework Core
    
- PostgreSQL
    

## Текущий статус

Проект находится на ранней стадии разработки.

**Реализовано:**

- Модели предметной области квиза.
    
- Настройка EF Core и связей между сущностями.
    
- Миграции базы данных.
    
- Сохранение тестового квиза в PostgreSQL.
    
- Асинхронная загрузка квиза с вопросами и ответами.
    
- Отображение квиза на странице с помощью Razor Views.
    
- Прототип отправки выбранного ответа через MVC-контроллер.
    

**Планируется:**

- Создание и редактирование квизов через веб-интерфейс.
    
- Управление вопросами и вариантами ответов.
    
- Создание игровых комнат.
    
- Подключение игроков и проведение квизов в реальном времени.
